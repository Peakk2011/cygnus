# Code of Conduct

## What I want

Everyone who contributes should be respectful and professional. I care about good code and working together.

## Good Behavior

- Be respectful when talking to others
- Listen to feedback
- Focus on fixing problems
- Own your mistakes

## Bad Behavior

- Being mean or rude to anyone
- Attacking people
- Sharing private information
- Threats or angry language

## Code Quality

Your code must:
- Work and be finished
- Follow our design and style rules
- Handle errors using our system
- Pass tests with no bugs

I don't accept broken code, incomplete work, or code that doesn't follow the rules.

## What Happens

Bad code gets rejected. Serious problems can get you removed from the project.
