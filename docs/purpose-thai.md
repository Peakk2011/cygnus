# เพราะอะไร

เราตั้งใจพัฒนา Cygnus (ไซนัท) สำหรับการแก้ปัญหาการเขียนภาษา HTML ที่ไม่มีความเป็นระเบียบทั้งด้านของการจัดการองค์ประกอบของเว็บไซต์
ให้มีประสิทธิภาพที่ดีมากขึ้น โดยไม่ต้องใช้ Framework ที่ใหญ่และเกินจำเป็นสำหรับระยะการทำงานของงานและตัวชี้วัดที่ถูกกำหนดไว้อย่างชัดเจนว่างานนี้ควรจะเป็นงานขนาดเล็กหรือใหญ่แค่ไหน
แต่สำหรับงานเล็กๆ การใช้เครืองมือที่ใหญ่เกินจำเป็น ทำให้ช้าและเกินความจำเป็นในบางแง่ของงานที่ควรจะเป็น เครืองมือ Cygnus จะแก้ปัญหาดังนี้
โดยจะเป็นการฝังการทำงานอยู่ในไฟล์ HTML (.html) และมี Syntax เสริมสำหรับการใช้งานคำสั่ง Cygnus เพิ่มเติม

# ตัวกำหนดและตัวชี้วัด

Cygnus เป็น preprocessor \ˌprē-ˈprä-ˌse-sər\ n
ที่มีคุณลักษณะและนิยามดังนี้
	1. เครื่องมือที่แปลงภาษา Markup แบบพิเศษให้เป็น HTML มาตรฐาน
	2. เป็นภาษาหรือระบบที่ประมวลผลไวยากรณ์คล้าย HTML ก่อนที่ Browser จะตีความ
	3. เครื่องมือที่ออกแบบมาเพื่อสร้าง HTML ที่สะอาดตาและ ดูแลรักษาง่าย จากภาษาต้นฉบับที่มีความยืดหยุ่นมากกว่า
	
Cygnus ไม่ใช่ Framework และ Cygnus เป็น preprocessor

ความหมายของคำว่า framework \ˈfrām-ˌwərk\ n
	1. รากฐานที่มีโครงสร้างที่ใช้สำหรับในการพัฒนาแอปพลิเคชัน
    2. ชุดเครื่องมือและกฎที่ช่วยให้การพัฒนาโปรแกรมง่ายขึ้น

# ไวยากรณ์ของ Cygnus

เครื่องมือนี้้มีไวยากรณ์ของตัวที่ ที่ไม่ยากเกินไป ไม่แปลกตาเกินไป อยู่ในระดับที่เป็นระดับของการใข้งานทั่วไปให้มีประสิทธิภาพสูงสุด
ในการทำงาน มากกว่าความสวยงามและการใช้งานที่เกินจำเป็น ตัวคัดกลองที่เป็นในนามของคนทำได้พัฒนาแล้วได้ใช้จริงมันสามารถทำงานได้ดี
ตัวไวยากรณ์ของเราในเชิงการใช้งานทั่วไป จะขึ้นต้นด้วยตัวอักษร '@' และ '*' เป็นการบอกว่าตัวนี้คือตัวแปร
